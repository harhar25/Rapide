## 🚀 Getting Started

### Step 1: Database Setup (1 minute)
```bash
mysql -u root -p after_sales_db < database/picklist_schema.sql
```

### Step 2: Restart Servers (1 minute)
```bash
python backend/run.py  # Backend
npm start              # Frontend
```

### Step 3: Test in Warehouse Dashboard (5 minutes)
1. Navigate to Warehouse Dashboard
2. Click "Parts Picklist" tab
3. Create test picklist (via API or Job Controller)
4. Click "Pick Items" and test

**Total Setup Time: ~10 minutes**
